Codora

AI-powered multiplayer quiz app for developers.

Codora makes learning programming fun, competitive, and intelligent.
Battle friends in real-time coding quizzes, earn XP, and learn faster with two AI tutors — Nime and Nesto — built on top of Google’s Gemini API.


---

🚀 Vision

Codora starts as a multiplayer quiz app but is evolving into a full AI-driven edtech ecosystem for developers.

A space where devs can:

Learn through games, challenges, and real projects.

Get feedback and mentorship from AI tutors.

Track their growth through XP, streaks, and skill analytics.

Compete with peers worldwide to sharpen their coding instincts.


> Codora’s mission: Make coding education addictive, smart, and personal.




---

🧠 Meet the AI Tutors

🪶 Nime

Your creative, curious, and conversational tutor. Nime explains concepts, helps you debug, and guides you through learning paths in a friendly, human tone.

⚡ Nesto

Your strategic, no-nonsense coach. Nesto focuses on performance — gives you tougher quizzes, tracks your stats, and pushes you to level up like a coding athlete.

Together, Nime and Nesto adapt to your learning style, making Codora feel like a real mentorship experience — not just another quiz app.

🧩 Tech Stack

Codora is built for speed, scalability, and mobile-first learning experiences.

Frontend Framework: React + Capacitor + Ionic

Language: TypeScript

Styling: Tailwind CSS

Backend & Realtime Data: Firebase (Auth, Firestore, Storage)

AI Integration: Gemini API (for question generation, tutoring, and recommendations)

⚙️ Setup

1. Clone the repo

git clone https://github.com/yourusername/codora.git
cd codora

2. Install dependencies

npm install

3. Add environment variables

Create a .env file in the project root and configure your Firebase + Gemini credentials:

VITE_FIREBASE_API_KEY=your_firebase_key  
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain  
VITE_FIREBASE_PROJECT_ID=your_project_id  
VITE_GEMINI_API_KEY=your_gemini_api_key

4. Run the app

npm run dev

To test on a mobile device:

npx cap open android
# or
npx cap open ios
