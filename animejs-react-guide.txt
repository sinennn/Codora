🚀 Getting Started with anime.js + React Hooks

Hey there! 👋  
This guide is for complete React beginners who want to learn how to:

- ✨ Animate stuff using `anime.js`
- 🧠 Use React state with `useState`
- 🕒 Run effects when components mount or update using `useEffect`

Let’s build a simple animated box that moves when a button is clicked.  
You’ll see `useState`, `useEffect`, and `anime.js` all in action!

---

🔧 Step 1: Setup Your Project

First, create a React app if you don’t already have one:

npx create-react-app my-anime-app
cd my-anime-app

Then install anime.js:

npm install animejs

---

📦 Step 2: Create the Animated Component

Let’s create a file called AnimatedBox.js inside the src/ folder.

// src/AnimatedBox.js
import React, { useState, useEffect, useRef } from 'react';
import anime from 'animejs';

export default function AnimatedBox() {
  const [moved, setMoved] = useState(false); // track if the box has moved
  const boxRef = useRef(null); // reference to the DOM element

  useEffect(() => {
    // Run this effect when `moved` changes
    anime({
      targets: boxRef.current,
      translateX: moved ? 250 : 0,
      duration: 1000,
      easing: 'easeInOutQuad',
    });
  }, [moved]);

  return (
    <div style={{ padding: '2rem' }}>
      <div
        ref={boxRef}
        style={{
          width: 100,
          height: 100,
          backgroundColor: 'tomato',
        }}
      />
      <button onClick={() => setMoved(!moved)} style={{ marginTop: '1rem' }}>
        {moved ? 'Reset' : 'Move'}
      </button>
    </div>
  );
}

---

🧠 Breakdown

🪄 `useState`
This is a React Hook that lets you add state (like memory) to a component.

const [moved, setMoved] = useState(false);

- `moved` is a variable (true or false)
- `setMoved` is a function that updates `moved`

We use this to track whether the box has moved or not.

⚙️ `useEffect`
This Hook runs code after the component renders.

useEffect(() => {
  // animation code
}, [moved]);

- The effect runs *every time* `moved` changes.
- Perfect for triggering animations!

💫 `anime.js`
This is an animation library for JavaScript.
It targets DOM elements and animates them with smooth transitions.

anime({
  targets: boxRef.current,
  translateX: 250,
  duration: 1000,
  easing: 'easeInOutQuad',
});

---

🧪 Step 3: Use It In App

Now open App.js and import the animated box:

import React from 'react';
import AnimatedBox from './AnimatedBox';

function App() {
  return (
    <div className="App">
      <h1>Welcome to Anime.js + React</h1>
      <AnimatedBox />
    </div>
  );
}

export default App;

---

🎉 Done!

Run your app:

npm start

Click the button and watch the box slide into action 💃
